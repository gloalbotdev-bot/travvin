# Deploy Travvin on Render

Architecture: **Static Site** (`travvin`) + **Web Service** (`travvin-api`).

| Service | Role | URL (example) |
|---|---|---|
| `travvin` | Vite/React frontend | `https://travvin.onrender.com` |
| `travvin-api` | Express API, crons, uploads | `https://travvin-api.onrender.com` |

DB: **Supabase Postgres** (same project as dev). Secrets only in Render env vars — never commit.

---

## Prerequisites

- [x] Render account + GitHub repo connected
- [x] `npm run test:server` passes locally
- [ ] `render.yaml` committed and pushed to `main`
- [ ] Google Cloud OAuth credentials
- [ ] Supabase `DATABASE_URL` + `DIRECT_URL`

---

## Step 1 — Push `render.yaml` to `main`

After review, merge to `main` and push. Do **not** apply Blueprint before `render.yaml` exists on `main`.

---

## Step 2 — Create Blueprint

1. Render Dashboard → **Blueprints** → **New Blueprint Instance**
2. Select repo `gloalbotdev-bot/travvin`, branch **`main`**
3. Review the two services from `render.yaml`
4. **Apply** (creates services; first deploy starts automatically)

Note the actual URLs Render assigns (may differ if names are taken).

---

## Step 3 — API secrets (`travvin-api` → Environment)

Copy from local `server/.env`. Replace `localhost` with prod URLs.

| Variable | Value |
|---|---|
| `DATABASE_URL` | Supabase pooler (`:6543`, `?pgbouncer=true`) |
| `DIRECT_URL` | Supabase direct (`:5432`) |
| `GOOGLE_CLIENT_ID` | Google Console |
| `GOOGLE_CLIENT_SECRET` | Google Console |
| `GOOGLE_REDIRECT_URI` | `https://<API-URL>/api/auth/google/callback` |
| `GOOGLE_CALENDAR_REDIRECT_URI` | `https://<API-URL>/api/connectors/google-calendar/oauth/callback` |
| `CALENDAR_TOKEN_ENCRYPTION_KEY` | `openssl rand -base64 32` (or reuse dev key) |
| `GEMINI_API_KEY` | Google AI Studio |

**Auto-wired by Blueprint** (do not override unless debugging):

| Variable | Source |
|---|---|
| `FRONTEND_URL` | Static site `RENDER_EXTERNAL_URL` |
| `PUBLIC_API_URL` | API `RENDER_EXTERNAL_URL` |
| `JWT_SECRET` | Generated by Render |

Optional SMTP: `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`.

**Email register without SMTP (Render):** set `ALLOW_CONSOLE_OTP=1` on `travvin-api` to log OTP codes in Render logs (dev/staging only). In production without SMTP or this flag, OTP codes are withheld from logs — configure SMTP for real email delivery.

After saving env vars → **Manual Deploy** on `travvin-api`, then redeploy `travvin` (static rebuild picks up API URL).

---

## Step 4 — Google OAuth (Google Cloud Console)

**APIs & Services → Credentials → OAuth 2.0 Client**

Add (keep localhost entries for dev):

**Authorized JavaScript origins:**
```
https://travvin.onrender.com
https://travvin-api.onrender.com
```

**Authorized redirect URIs:**
```
https://travvin-api.onrender.com/api/auth/google/callback
https://travvin-api.onrender.com/api/connectors/google-calendar/oauth/callback
```

Use your actual Render URLs if different.

Same project as dev → tables already exist. No migration needed.

## Plan: Free vs Starter

| | **Free** | **Starter ($7/mo)** |
|---|---|---|
| API sleep | Yes (~15 min idle) | No |
| Cold start | 30–60 s | Minimal |
| Persistent Disk (uploads) | No | Yes |
| Static Site | Free always | Free always |

**Recommendation:**

- **First smoke:** Free — uploads are ephemeral (lost on redeploy)
- **Real prod:** Starter on `travvin-api` + uncomment `disk` block in `render.yaml`

To enable persistent uploads:

1. Change `travvin-api` plan to **Starter**
2. Uncomment `disk` section in `render.yaml`, push, redeploy
3. `STORAGE_LOCAL_DIR=/var/data/uploads` is already set

## Troubleshooting

| Symptom | Fix |
|---|---|
| Google login fails | Match redirect URIs in Google Console + Render env exactly |
| `db: false` on health | Check `DATABASE_URL` / `DIRECT_URL` |
| CORS error in browser | Redeploy API after `FRONTEND_URL` is wired; check static URL |
| Images 404 | Set `PUBLIC_API_URL` to API URL; redeploy API |
| Uploads vanish after redeploy | Upgrade to Starter + enable disk |
| API slow first request | Free tier cold start — wait or upgrade to Starter |
